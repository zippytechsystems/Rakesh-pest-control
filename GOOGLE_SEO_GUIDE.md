## Part 2: Google Search Console (GSC) Setup & Indexing

Google Search Console ensures that Google's search crawlers discover, crawl, and rank all pages of the Harsha Pest Control website.

### Step 1: Add Property to Search Console
- **Status:** **[Owner Action Required]**
- **Action:**
  1. Go to [search.google.com/search-console](https://search.google.com/search-console/).
  2. Click **Add Property**.
  3. Select **Domain** (e.g. `harshapestcontrol.store`) or **URL Prefix** (`https://harshapestcontrol.store`).

### Step 2: Verify Website Ownership
- **Status:** **[Owner Action Required]**
- **Preferred Method (DNS TXT Record):**
  - If using domain registrars (Hostinger, GoDaddy, Namecheap):
    1. Copy the TXT record token provided by Google Search Console (e.g., `google-site-verification=abc123xyz...`).
    2. Add a DNS TXT record with Host `@` and Value `google-site-verification=abc123xyz...`.
    3. Click **Verify** in Search Console.
- **Alternative Method (HTML Meta Tag):**
  - Copy the verification meta tag `<meta name="google-site-verification" content="..." />` and insert it into the `<head>` of `index.html`.

### Step 3: Submit XML Sitemap
- **Status:** **[Owner Action Required]**
- **Action:**
  1. Once verified, navigate to **Sitemaps** in the left sidebar menu.
  2. In the "Add a new sitemap" input box, type:
     ```
     sitemap.xml
     ```
  3. Click **Submit**.
  4. Confirm that the status changes to **Success** and that Google recognizes all canonical pages (`index.html`, etc.).

### Step 4: Request Immediate Indexing with URL Inspection
- **Status:** **[Owner Action Required]**
- **Action:**
  1. In the top search bar ("Inspect any URL in harshapestcontrol.store"), enter:
     ```
     https://harshapestcontrol.store/
     ```
  2. Press **Enter**. Search Console will fetch the current index status.
  3. Click **Test Live URL** to verify mobile usability and Schema.org structured data.
  4. Click **Request Indexing**. This places the site into Google's priority crawl queue.
